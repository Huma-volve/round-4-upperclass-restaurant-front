# 🍽Restaurant Website

##  Features

-  React + TypeScript for scalable, maintainable code.
-  Tailwind CSS for rapid and responsive styling.
-  Sass for reusable and clean component-based styles.
-  Framer Motion for smooth and modern animations.
-  React Hook Form for flexible and performant forms.
-  Zod for schema-based form validation.
-  Fully responsive design for mobile, tablet, and desktop.
-  Reusable UI components.
-  Sections: Hero, Menu, About, Reservation Form, Testimonials, Contact.

git clone https://github.com/your-username/restaurant-project.git
